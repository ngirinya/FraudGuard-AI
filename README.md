# FraudGuard AI

An intelligent financial fraud detection platform
built with Python and Machine Learning.

## Project Objectives

- Analyse financial transactions.
- Identify suspicious transaction patterns.
- Train machine learning models.
- Predict potentially fraudulent transactions.
- Generate fraud risk reports.
- Provide an interactive fraud monitoring dashboard.

## Technologies

- Python
- NumPy
- Pandas
- Scikit-learn
- Streamlit
- FastAPI
- SQL
